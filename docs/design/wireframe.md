# 프론트엔드 와이어프레임

여기에 화면 설계 이미지나 설명을 추가해줘.

## 추가 방법

이미지 파일(PNG, JPG 등)을 이 폴더(`docs/design/`)에 넣고 아래처럼 연결하면 돼.

```markdown
![메인 페이지](./main.png)
![검색 결과](./search.png)
![연예인 상세](./celebrity-detail.png)
```

---

## 화면 목록 (설계 대상)

| 화면 | 설명 |
|---|---|
| 메인 | 검색창, 인기 연예인/아이템 |
| 검색 결과 | 연예인 카드 + 착장 목록 |
| 연예인 상세 | 프로필 + 전체 착장 목록 |
| 아이템 상세 | 아이템 정보 + 구매 링크 + 이 아이템 착용한 연예인 |
| 착장 등록 | 연예인 선택 → 아이템 선택/등록 → 콘텐츠 정보 입력 |
| 편집 이력 | 위키처럼 변경 내역 목록 |
